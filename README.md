# XO E-Pin

Modern, responsive static e-pin storefront for GitHub Pages.

## Included
- Responsive homepage
- Category filters and search
- LocalStorage cart
- WhatsApp order summary flow
- Login/register/contact demo pages
- Existing product images and legacy category pages preserved

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

> Note: Real payment, membership, inventory and automatic code delivery require a backend/payment provider integration. The current version is a static storefront frontend.
